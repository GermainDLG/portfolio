Goals:

1. ✓ Getting the original source
Currently in the dashboard under each article, it lists its source as the newsletter that article was received from. Instead, it should list the actual publisher of the article. For example, some newsletters include links to X posts, other articles, github links, etc., but still list the newsletter as the source. Going forward, the source should just be changed to include the original publisher or location of the article, not the newsletter itself. It should only display the newsletter if it was an opinion piece posted by that newsletter itself.

2. ✓ Collapsable side panels
Currently on the dashboard, there is a recipients side panel where you can add or remove recipients. It is collapsable. On the other side, there is a source tab, which is not collapsable. It should be made collapsable.

3. ✓ removing email from the email sources
Currently, email sources are labeled as "(email name) <Email Address>". They should be changed to just the email name. ex: AlphaSignal <news@alphasignal.ai> --> AlphaSignal

4. making it a word doc instead of email
Currently, pressing send newsletter once will bring up the text editor. Pressing it again will send the newsletter to the recipient list. Instead, I think these buttons should be changed to be "Create Doc" and "Download" respectively. The goal of this newsletter has changed. It will no longer directly send to the viewers. Instead, it will format everything into a word doc, where the owner of the newsletter will download it so he can edit the formatting. From there, he will copy paste everything into an email to send out. Something to note is that the current editing will stay there. That is considered the "Broad" editing that is to be kept. The purpose of downloading it as a word doc is to do more fine grain editing.

5. ✓ Changing it to be quicksilver instead of mercury fund
Currently, all pages say "Mercury Fund AI Digest" In the top left. It should be changed to "Quicksilver Labs Newsletter" instead.

6. Clicking source shows just that one
Currently, the sources tab on the left just serves to show how many items were found for each source. This should be changed so that, when a source is clicked, it will filter to just be all articles found from that source. Only one source can be selected at a time, and selecting a source once it is already selected will unselect it. The articles will stay in their buckets, and empty buckets can just go away.

7. ✓ paywalled in one liners needs to changed
Currently, all articles within the "Manual Review & One-Liners" Topic have a "PAYWALLED" label. However, not all of these articles are paywalled. This label should be changed to be "Manual Review".

8. ✓ Other above one-liners
Currently, the "Others" bucket is at the very bottom, with "Manual Review & One-Liners" above it. This is an issue because "Manual Review & One-Liners" can be very long. Because of this, I want the "Manual Review & One-Liners" section to be below other. The order should be:
All topics -> Other -> Manual Review & One-Liners -> Accepted -> Rejected
